| HOW TO CHANGE ENCOUNTER THEME |
|_______________________________|

Encounter file to replace:
...\pokemmo\data\mods\Mod-Catppuccin-Mocha-x.x\Theme-Catppuccin-Mocha\res\counter-theme.png

- Replace counter-theme.png with another one from the counter-themes folder. (...\pokemmo\data\mods\Mod-Catppuccin-Mocha-x.x\Theme-Catppuccin-Mocha\res\counter-themes)
- Tip: Instead of deleting the previous counter-theme.png, you can rename it to eg. counter-theme2.png etc. The game will only load the counter-theme.png as the encounter counter theme and ignore files that are named differently

- Keep in mind that there has to be a counter-theme.png inside the res folder, else the Catppuccin theme will crash and the game will use the default theme instead.
